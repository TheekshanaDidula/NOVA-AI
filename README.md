# NOVA AI

A personal AI voice assistant powered by Google Gemini.

## Features

- AI-powered conversations
- Sinhala and English support
- Voice input
- AI voice responses
- Text chat interface
- Secure API key handling

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Google Gemini API

## Setup

1. Clone the repository.
2. Install dependencies:

   npm install

3. Create a `.env` file.
4. Add your Gemini API key:

   GEMINI_API_KEY=your_api_key
   PORT=3000

5. Start the application:

   npm start

## Security

Never upload your actual API key or `.env` file to GitHub.
